Detailed Description

cheatah builtins — Python's always-available built-ins (no import): length, character/representation conversions, and hashing.

The compiler auto-includes this header and resolves bare calls like len("x") to builtins::len. The mathematical built-ins (abs/min/max/round/pow) live in the math module. Unit tests: stdlib/tests/builtins_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.
