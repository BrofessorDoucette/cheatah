Class

socket::Listener

An owning listening socket; accept() yields owning Conn clients; the destructor closes it.

The server-side RAII guard: with socket.serve(host, port, backlog) as server { … } keeps the listening fd for the block and closes it on exit. Each accept() returns an owning Conn, so a whole server loop leaks neither the listener nor its clients. Move-only, like Conn.
