1// Compile-run unit tests for the `linalg` module: one test per purr-callable
2// function. Each writes a tiny .purr that calls a single linalg routine on a
3// small fixed matrix/vector, compiles it with purrc, runs it under the cheatah
4// runtime, and asserts the exact stdout. Results are chosen to be integer-valued
5// (or exactly representable) so the io.print formatting is deterministic.
6// Complements the in-process unit tests (stdlib/tests/linalg_routines_test.cpp),
7// the per-module system test (StdlibE2E.Linalg), and the least-squares system
8// test (linalg_lsq_e2e_test.cpp).
9#include "e2e_harness.hpp"
10
