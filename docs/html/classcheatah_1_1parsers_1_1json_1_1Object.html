Class

parsers::json::Object

A JSON object token, templated on its backing storage S: Object<std::vector<Member>> (OwnedObject) owns its members, Object<std::span<const Member>> (ObjectView) views members in a Parser's pool with no copy.

Move-only; both backings read uniformly via value().

Template parameters
S

the member storage: std::vector<Member> (owning) or std::span<const Member> (viewing).
