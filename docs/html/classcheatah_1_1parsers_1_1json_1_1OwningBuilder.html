Class

parsers::json::OwningBuilder

The construction policy for the OWNING JSON parse path: the same stack-machine interface as PoolBuilder (begin/add/finish), but each container is built in its own std::vector and, on finish, the whole vector is moved into an OwnedArray/OwnedObject (O(1), no per-element copies).

Strings are copied too, so the resulting Document owns its entire tree and is independent of any Parser, pool, or source buffer. A plain policy type (no polymorphism).
