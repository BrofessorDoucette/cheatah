1// Compile-run unit tests for the `os` module: one test per function. Each writes
2// a tiny .purr that calls a single os (or os.path) function, compiles it with
3// purrc, runs it under the cheatah runtime, and asserts the exact stdout.
4// Complements the in-process unit tests (stdlib/tests/os_test.cpp) and the
5// per-module system-level test (StdlibE2E.Os).
6//
7// Programs must be DETERMINISTIC. Purely-lexical os.path helpers print their
8// result directly. Filesystem functions operate under a UNIQUE /tmp directory
9// created inside the .purr and print a deterministic property (e.g. mkdir then
10// os.path.isdir -> True). Non-deterministic functions (getpid, getcwd,
11// cpu_count, system exit status, getenv of a process-set var) assert a
12// deterministic property instead of the raw value.
13//
14// SKIPPED: none — every os/os.path function below is covered. The only thing
15// that cannot be printed directly is os.path.splitext (returns a std::pair, not
16// io.print-Streamable); it is covered via the pair's `.first`/`.second` members.
17#include "e2e_harness.hpp"
18
