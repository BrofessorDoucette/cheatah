Detailed Description

cheatah random — pseudo-random numbers, mirroring the core of Python's random module.

Backed by a seedable Mersenne Twister (std::mt19937_64); gauss gives normal deviates for Monte Carlo. import random to use it.

Unit tests: stdlib/tests/random_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.

Doc convention (see also the other stdlib headers): each function notes its runtime complexity, whether it touches the heap, and the
