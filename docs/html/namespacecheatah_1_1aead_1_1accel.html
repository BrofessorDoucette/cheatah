aead::accel

Functions

fn bool available() source#

Always false on this architecture: there is no AES hardware path, so callers fall back to the portable scalar AES-128-GCM reference.

Returns

false (no hardware acceleration available here).

fn std::string aes128gcm_encrypt(const unsigned char key[16], const unsigned char nonce[12], std::string_view aad, std::string_view plaintext) source#

Unreachable stub so the accel namespace type-checks on non-accelerated targets; never called because available() is false.

Signature matches the accelerated aes128gcm_encrypt.

Parameters
key

the 16-byte AES-128 key (ignored).

nonce

the 12-byte GCM nonce/IV (ignored).

aad

additional authenticated data (ignored).

plaintext

the message to encrypt (ignored).

Returns

the empty string (this path is never taken).

fn std::string aes128gcm_decrypt(const unsigned char key[16], const unsigned char nonce[12], std::string_view aad, std::string_view ciphertext) source#

Unreachable stub so the accel namespace type-checks on non-accelerated targets; never called because available() is false.

Parameters

nonce

aad
