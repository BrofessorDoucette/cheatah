Detailed Description

cheatah math — scalar math: Python's math module plus the abs/min/max/pow built-ins.

import math to use it.

Every function here is pure and allocation-free (operates on double / long long by value). Unit tests: stdlib/tests/math_test.cpp. The whole suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.
