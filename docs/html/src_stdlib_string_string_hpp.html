5 * @brief cheatah `string` — text operations + Python's `string` constants,
6 * surfaced as free functions (a .purr program writes `string.upper("x")`).
7 *
8 * `import string` includes this header and links `libcheatah_string`. Unit tests:

12 * @note Functions returning `std::string` / `std::vector<std::string>` allocate

333/// StringViewable<T>: a `std::string_view` can be built from T — what join() needs.
334template <typename T>
335concept StringViewable = requires(const T& v) { std::string_view(v); };
336
337/**
338 * Join @p parts with @p sep.
339 *
340 * Concatenates each element of @p parts with @p sep inserted only between elements
341 * (no leading or trailing separator); an empty range yields an empty string.
342 * @param sep separator.
343 * @param parts any range of string-like values.
344 * @return the joined string.
345 * @complexity O(total length).
346 * @alloc allocates the result.
347 * @test CheatahString.Transform
348 * @crtest StringCompileRun.Join
349 * @systest StdlibE2E.String
350 */
351template <std::ranges::input_range Range>
352 requires StringViewable<std::ranges::range_value_t<Range>>
353std::string join(std::string_view sep, const Range& parts) {
354 std::string out;
355 bool first = true;
356 for (const auto& part : parts) {
357 if (!first) {
358 out += sep;
359 }
360 out += std::string_view(part);
361 first = false;
362 }
363 return out;
364}
