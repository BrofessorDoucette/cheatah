2// the per-function compile-run tests (tests/purrc/statistics_cr_test.cpp), this

4// purr-callable statistics function and asserts its exact stdout, so the
5// functions are exercised together against the same data.
6//
7// Fixed dataset {2,4,4,4,5,5,7,9}: sum 40, count 8, mean 5, pvariance 4,
8// pstdev 2, variance 32/7 (≈4.57143), stdev sqrt(32/7) (≈2.13809), median 4.5
9// (mean of the two middle values 4 and 5). Fully deterministic.

11// Coverage — every function in stdlib/statistics/statistics.hpp:
12// sum, count, mean, pvariance, pstdev, variance, stdev, median.
