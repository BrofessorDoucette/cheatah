Detailed Description

cheatah hashlib — cryptographic hashing, mirroring the core of Python's hashlib.

import hashlib to use it.

import hashlib includes this header AND links libcheatah_hashlib. Provides a self-contained SHA-256 (no external crypto dependency) returning a lowercase hex digest. Unit tests: stdlib/tests/hashlib_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.
