Detailed Description

cheatah time — high-accuracy timing.

Mirrors the timing core of Python's time module, built on C++ <chrono> clocks (system_clock for wall-clock, steady_clock for monotonic high-resolution counters). import time to use it.

Unit tests: stdlib/tests/time_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.
