5/**
6 * @file regex.hpp
7 * @brief `regex` — a fast, from-scratch regular-expression engine. `import regex`.
8 *
9 * A **linear-time** matcher: the pattern compiles to a Thompson NFA and runs as a **lazy
10 * DFA** (RE2-style), so matching is O(n) in the input length with **no backtracking** — it
11 * cannot blow up exponentially on adversarial patterns the way `std::regex` and backtracking
12 * engines (Boost) do. An unanchored @ref search is ONE forward DFA pass (the compiled-in
13 * `.*?` prefix tracks every start position simultaneously), accelerated by a `memchr`/
14 * literal/first-set skip whenever the scan has no partial match alive; a `$`-anchored search
15 * runs a reversed program **backward from the end**, dying after a handful of bytes when the
16 * tail cannot match. Only @ref find on input that *does* contain a match may retry candidate
17 * starts (leftmost-longest is decided per start), so its worst case is quadratic — still
18 * polynomial, never exponential; see each function's `@complexity`. A compiled @ref Pattern
19 * owns its program **and a reusable DFA cache** (start states included), so repeated matches
20 * over one pattern warm the cache and pay only a byte-table lookup per input character. It is
21 * statically typed and **never allocates an intermediate string**: matching touches only the
22 * input bytes (as a `string_view`) and integer program-counters. @ref find
23 * returns the matched bytes as an **owned `str`** (the library owns them — no borrow, so nothing
24 * can dangle), plus the byte offsets for callers who prefer to slice their own input zero-copy.
25 *
26 * Supported syntax (a pragmatic subset): literals; `.` (any byte except newline); character
27 * classes `[...]` with ranges and negation `[^...]`; the escapes `\d \D \w \W \s \S` and
28 * escaped metacharacters (`\. \* \\` …); the quantifiers `* + ?`; alternation `|`; grouping
29 * `(...)`; and the anchors `^` `$`. (Backreferences and lookaround are intentionally out of
30 * scope — they are what force backtracking and the exponential blowups this engine avoids.)
31 */
32#include <cstddef>
33#include <memory>
34#include <string>
35#include <string_view>

37namespace cheatah::regex {

39/// The compiled program plus its lazy-DFA cache (an opaque implementation type; defined in the
40/// translation unit). A @ref Pattern shares one by value.
41struct Dfa;
42
43/// A compiled regular expression. Value-semantic: it shares a compiled program + DFA cache, so
44/// copying is cheap and reuse is fast. Build it once with @ref compile, then match many times.
45struct Pattern {
46 std::shared_ptr<Dfa> impl; ///< the compiled program + reusable DFA cache (nullptr if !ok).
47 bool ok = false; ///< false if @ref compile rejected the source (see @ref error).
48 std::string error; ///< a human-readable reason when `ok` is false.
49};
50
51/**
52 * Compile @p pattern into a reusable @ref Pattern. Never throws — on a malformed pattern it
53 * returns a `Pattern` with `ok == false` and a message in `error`. Patterns longer than
54 * 64 KiB are rejected as malformed (`"pattern too long"`): compilation spends O(m) memory,
55 * and the cap bounds what a crafted pattern can make it allocate.
56 * @param pattern the regular-expression source.
57 * @return the compiled pattern (check `.ok`).
58 * @complexity O(m) in the pattern length.
59 * @alloc the compiled program + DFA cache on the heap (owned by the returned Pattern).
60 * @systest RegexE2E.MalformedPatternReportsNotOk
61 * @systest RegexE2E.SearchPresentAbsent
62 */
63Pattern compile(std::string_view pattern);
64
65/**
66 * Whether @p re matches **anywhere** in @p text (an unanchored search).
67 * @param re a compiled pattern.
68 * @param text the input to search.
69 * @return true if some substring of @p text matches.
70 * @complexity O(n) — one DFA pass, always: anchored patterns run forward from the start;
71 * `$`-anchored patterns run a reversed program backward from the end (typically
72 * exiting after a few tail bytes); everything else is a single unanchored forward
73 * pass whose built-in `.*?` prefix tracks all start positions at once, skipping
74 * ahead via `memchr`/required-literal/first-set pruning whenever no partial match
75 * is alive. Add O(m) per uncached transition while new DFA states are still being
76 * built (m = pattern size).
77 * @alloc never copies the input; allocates only DFA machinery — new states/transition rows
78 * while the shared cache is cold (start states are cached in the Pattern after the
79 * first call; a warm pattern allocates nothing).
80 * @warning a pathological pattern whose lazy DFA exceeds the state budget (100k states) throws
81 * `std::runtime_error` rather than exhausting memory.
82 * @systest RegexE2E.SearchPresentAbsent
83 * @systest RegexE2E.ReDoSNestedQuantifierReturnsFalseFast
84 */
85bool search(const Pattern& re, std::string_view text);
86
87/**
88 * Whether @p re matches the **entire** @p text (anchored at both ends).
89 * @param re a compiled pattern.
90 * @param text the input.
91 * @return true iff all of @p text matches.
92 * @complexity O(n) amortized in the length of @p text (a single anchored DFA pass); O(n·m) worst
93 * case while new DFA states are still being built (m = pattern size).
94 * @alloc never copies the input; allocates only DFA machinery — new states/transition rows while
95 * the shared cache is cold (start states are cached in the Pattern after the first call; a
96 * warm pattern allocates nothing).
97 * @warning a pathological pattern whose lazy DFA exceeds the state budget (100k states) throws
98 * `std::runtime_error` rather than exhausting memory.
99 * @systest RegexE2E.FullMatchIsAnchoredBothEnds
100 */
101bool full_match(const Pattern& re, std::string_view text);
102
103/// The result of @ref find: the leftmost-longest match. @ref text is an **owned `str`** — the library
104/// copies the matched bytes into it, so it stays valid no matter what happens to the input (no borrow,
105/// no dangling). @ref begin / @ref end are the byte offsets into the input, for callers who would
106/// rather slice their own (already-owned) input zero-copy instead of using the copy.
107struct Match {
108 bool matched = false; ///< whether a match was found.
109 std::size_t begin = 0; ///< byte offset of the match start in the input.
110 std::size_t end = 0; ///< byte offset one past the match end.
111 std::string text; ///< the matched bytes — OWNED (empty when `!matched`).
112};
113
114/**
115 * Find the **leftmost-longest** match of @p re in @p text and return it as a @ref Match — the byte
116 * offsets plus `.text`, an **owned copy** of the matched bytes (safe to keep past @p text).
117 * @param re a compiled pattern.
118 * @param text the input to search.
119 * @return the match (check `.matched`); `.text` owns the matched bytes.
120 * @complexity a `$`-anchored pattern is O(n): one backward pass of the reversed program
121 * finds the leftmost begin directly. Otherwise candidate starts are tried from
122 * the left (leftmost-longest is decided per start), with the `memchr`/required-
123 * literal/first-set skip jumping between plausible candidates — so sparse-
124 * candidate input is effectively O(n), while a late match over candidate-dense
125 * input is O(n²) worst case — always polynomial, never exponential (no
126 * backtracking). Absent input stays O(n): after a budget of failed candidates one
127 * unanchored pass settles existence. Add O(m) per uncached transition while new DFA
128 * states are built.
129 * @alloc the matching itself never copies the input — it allocates only DFA machinery (new
130 * states while the shared cache is cold; start states are cached in the Pattern, so a
131 * warm pattern's scan allocates nothing); on a hit, `.text` owns one copy of the
132 * matched bytes (`end - begin`). Use `.begin`/`.end` to avoid even that.
133 * @warning a pathological pattern whose lazy DFA exceeds the state budget (100k states) throws
134 * `std::runtime_error` rather than exhausting memory.
135 * @systest RegexE2E.FindOffsetsAndOwnedText
136 * @systest RegexE2E.FindIsLeftmostLongest
137 */
138Match find(const Pattern& re, std::string_view text);
