Detailed Description

cheatah statistics — descriptive statistics over numeric sequences, mirroring Python's statistics module.

import statistics to use it.

Header-only: every function is a template constrained by the NumericRange concept, so it accepts any iterable of arithmetic values (list[float], array[int], …) and is instantiated at the call site. Unit tests: stdlib/tests/statistics_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.

Note
n below is the element count. Single-pass reductions are O(n) and allocation-free; median is the exception (it materializes and sorts a copy). Results are scalar double/std::size_t — no heap on return.
