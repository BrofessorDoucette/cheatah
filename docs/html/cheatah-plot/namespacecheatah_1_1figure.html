Module

figure

cheatah-plot v0.1.1-alpha — Biome Standard 0.6.5-alpha

Classes

  • Axis — One axis: label, transform, limits, and a target tick count.
  • Figure — The whole figure: a rows×cols grid of subplots, pixel size, the categorical palette, and the index fluent calls currently target.
  • Scale — An axis transform choice ("linear" or "log") — a tiny struct instead of an enum, per the house style; make one with linear() / log_scale().
  • Subplot — One cell of the figure grid: a title, two axes, the series drawn in it, and a legend flag.
