Detailed Description

cheatah io — Python-like input/output, surfaced as free functions and a File object (a .purr program writes io.print(...), io.open(...)).

Mirrors https://docs.python.org/3/tutorial/inputoutput.html.

import io includes this header AND links the io library (libcheatah_io); a program that doesn't import io neither sees nor links it. Unit tests: stdlib/tests/io_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.

Note
Templated entry points live here (they monomorphize at the call site → tight machine code); the non-template symbols are compiled into the library.
