1// System-level test for the cheatah `os` standard-library module.
2//
3// Unlike os_cr_test.cpp (one tiny program per function), this is a SINGLE
4// cohesive filesystem workflow that exercises EVERY public function in
5// stdlib/os/os.hpp in one program: it builds a nested directory tree, creates
6// and renames and removes files (writing content via os.system), queries them
7// (exists/isfile/isdir/getsize/listdir), changes directory, applies the
8// purely-lexical os.path helpers, round-trips an environment variable, and
9// reports the process/system facts. Everything happens under a unique /tmp
10// workspace that is torn down at the end.
11//
12// Output is DETERMINISTIC: filesystem state is fully controlled, and the
13// non-deterministic facts (getpid, getcwd, cpu_count, the exit status of
14// `false`) are asserted as PROPERTIES (pid > 0, cpu_count >= 1, cwd basename,
15// false != 0) rather than printed raw.
16//
17// Coverage (all 24 public functions):
18// os.* getcwd chdir listdir mkdir makedirs rmdir remove rename
19// getenv setenv cpu_count system getpid urandom
20// os.path.* join exists isfile isdir basename dirname abspath getsize
21// splitext normpath
22//
23// splitext returns a std::pair (not io.print-Streamable); it is read via the
24// pair's .first / .second members, matching os_cr_test.cpp.
25#include "e2e_harness.hpp"
26
