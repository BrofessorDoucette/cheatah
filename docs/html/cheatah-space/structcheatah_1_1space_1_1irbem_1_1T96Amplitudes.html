space::irbem::T96Amplitudes

cheatah-space v0.1.0-alpha — Biome Standard 0.6.4-alpha

The 128 amplitudes for one epoch and one driver set, plus the tilt's sine and cosine.

Everything t96_components needs beyond the point. The float instantiation is how the host lane is made to run the device kernel's arithmetic: the collapse is done in double and rounded ONCE, so both lanes multiply the same float amplitudes against the same float basis.
