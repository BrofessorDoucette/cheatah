Struct

space::irbem::T01State

cheatah-space v0.1.0-alpha — Biome Standard 0.6.4-alpha

Everything the evaluator needs that is a property of the EPOCH and the DRIVERS rather than of the point: the tilt, the module amplitudes of P2 eq.

(11), the interconnection vector, the short module's inner-edge shift and the Birkeland scaling factors.

Resolved once by t01_state and read by every point; this is also, float for float, the device kernel's parameter block (t01_param_block). The float instantiation is how the host fp32 lane is made to run the same arithmetic as the device: the amplitudes are formed in double and ROUNDED, so a host-device disagreement is attributable to the device.

Template parameters

the scalar type; double for the reference lane, float to mirror the kernel.
