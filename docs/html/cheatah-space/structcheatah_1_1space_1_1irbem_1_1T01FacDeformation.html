Struct

space::irbem::T01FacDeformation

cheatah-space v0.1.0-alpha — Biome Standard 0.6.4-alpha

The azimuthal deformation of the Birkeland field, P1 eq.

(21), and its constants (¶47-48).

F = phi - (Delta phi + b (rho^2 - 1) / (rho^2 + rho_0^2)) sin phi - beta Psi / [1 + (r / R_H)^ epsilon]^(1 / epsilon), in cylindrical coordinates about y_GSM with phi = -arctan(z / x). The first term shifts the ovals to the nightside, the second drags them with the dipole tilt.

Constants & variables

var std::array< double, 2 > delta_phi #

Delta phi, radians, per region: "0.055 and 0.030 for the Region 1 and 2 currents".

var double b #

b, the amplitude of the distance-dependent nightside shift; 0.5.

var double rho_0 #

rho_0, R_E — where that shift saturates; 7.0.

var double beta #

beta, the "slippage" between the Earth and the oval under tilt; 0.9.

var double r_h #

R_H, R_E — the hinging distance of the tilt dragging; 10.

var double epsilon #

epsilon, the radial sharpness of the dragging profile; 3.
