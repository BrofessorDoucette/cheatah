space::irbem::T01Coefficients

cheatah-space v0.1.0-alpha — Biome Standard 0.6.4-alpha

P2 Table 1: the 24 linear coefficients and the non-linear parameters this file reads.

The ring-current entries (s, p, xi_S0, beta_S, xi_P0, beta_P, Dst_0*) and the magnetopause compression index kappa are published in the same table and NOT carried here, because they multiply bases this file does not have (see the file brief). Carrying numbers that nothing reads would be a claim of completeness the code cannot back.

Unit testIrbemT01.PublishedTablesAreTranscribed
