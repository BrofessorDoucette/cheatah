Detailed Description

cheatah os — Python-like operating-system interface over std::filesystem, plus the os.path submodule.

import os to use it.

import os includes this header AND links libcheatah_os. Templated entry points (e.g. os.path.join) live here; the rest is compiled into the library. Unit tests: stdlib/tests/os_test.cpp; the suite runs under AddressSanitizer (the asan preset) and Valgrind (security/run-valgrind.sh) on every QA-gate run.

Note
Most calls touch the filesystem/environment, so they perform a syscall in addition to the cost noted per function; n is the path length.
