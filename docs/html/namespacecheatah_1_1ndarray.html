fn std::vector< std::size_t > broadcast_shapes(const std::vector< std::size_t > &a, const std::vector< std::size_t > &b) source#

The broadcast result shape of two shapes (NumPy rules).

Aligns the shapes from the trailing (rightmost) dimension, treating missing leading dims as 1; each output dim is the non-1 input dim, and two unequal dims that are both not 1 are incompatible and throw.

Parameters
a

first shape.

b

second shape.

Returns

the broadcast shape (trailing-aligned).

Complexity

O(max(ndim)).

Allocation

allocates the small result vector; throws if the shapes are incompatible.

fn NDArray broadcast_to(const NDArray &a, const std::vector< std::size_t > &target) source#

A zero-copy view of a stretched to target (size-1 / missing dims get stride 0).

Right-aligns a's dims under target, keeping the original stride where dims match and using stride 0 where a size-1 (or missing leading) dim is stretched; throws if a has more dims than target or a non-1 dim doesn't match the target.

Parameters
a

source array.

target

the shape to stretch to.

Returns

a VIEW sharing a's buffer (no element copy).

Complexity

O(target ndim).

Allocation

allocates only the small strides vector for the view, not the data; throws if a is not broadcastable to target.

fn NDArray arange(double start, double stop, double step) source#

1-D range [start, stop) stepping by step (Python range-like).

Accumulates values from start, advancing by step while below stop (or above it when step is negative), so a step pointing away from stop yields an empty array; throws when step is zero. Uses floating-point accumulation, so rounding may affect the final count.

Parameters
start

first value.

stop

exclusive bound.

step

increment (non-zero).

Returns

a 1-D NDArray of the generated values.

Complexity

O(count) where count = number of steps.

Allocation

allocates a new NDArray buffer (shared_ptr<vector<double>>); throws if step is zero.

fn NDArray reshape(const NDArray &a, const std::vector< long long > &shape) source#

Reshape a to shape (same element count).

Reads a's elements in C-order (so it works through arbitrary views/broadcasts) into a brand-new contiguous buffer with the requested shape, i.e. it copies rather than aliasing; throws if the new size differs from a's or any dim is negative.

Parameters

source array.

shape

the new dimensions (rejects negatives).

Returns

a new contiguous NDArray with the data laid out in C-order.

Complexity

O(size).

Allocation
