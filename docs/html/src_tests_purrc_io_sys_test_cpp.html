1// System-level (whole-module) test for the `io` stdlib module: ONE cohesive .purr
2// program that exercises EVERY public purr-callable entry point in stdlib/io/io.hpp
3// in a single run, compiles it with purrc, runs it under the cheatah runtime, and
4// asserts the exact stdout byte-for-byte. Complements the per-function compile-run
5// tests (tests/purrc/io_cr_test.cpp) and the in-process unit tests
6// (stdlib/tests/io_test.cpp).
7//
8// Coverage (every documented purr-callable symbol in io.hpp):
9// io.str (generic Streamable overload) -> io.str(3), io.str(os.remove(...))
10// io.str (bool overload) -> io.str(1 == 1) / io.str(1 == 2) -> True/False
11// io.str (std::string identity) -> io.str(name)
12// io.repr (std::string overload) -> io.repr(name), io.repr(first), io.repr(rest)
13// io.repr (const char* overload) -> io.repr("raw")
14// io.print -> used throughout
15// io.format -> summary + the file body
16// io.open (free function) -> let f/g/h = io.open(path, mode)
17// File.write -> f.write(...)
18// File.is_open -> f.is_open() before/after close
19// File.close -> f.close()
20// File.read -> g.read()
21// File.readline -> g.readline()
22// File.readlines -> h.readlines()
23// io.read_file -> io.read_file(path)
24//
25// io.input is intentionally NOT covered: it reads from stdin, which the e2e harness
26// does not feed (covered instead by the in-process test CheatahIo.InputReadsALine).
27//
28// The program builds strings with str/repr/format, writes a temp file under /tmp via
29// the File object, reads it back three ways (readline+read, readlines, read_file),
30// prints a deterministic summary, then deletes the temp file (os.remove) and confirms
31// it is gone (os.path.exists). os is imported only for path joining and cleanup.
32#include "e2e_harness.hpp"
