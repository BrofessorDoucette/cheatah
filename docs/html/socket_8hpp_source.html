3/**
4 * @file socket.hpp
5 * @brief cheatah `socket` — a small wrapper around BSD/POSIX TCP sockets,
6 * in the spirit of Python's `socket`. `import socket` to use it.
7 *
8 * cheatah has no methods yet, so the API is **flat and file-descriptor based**
9 * (like the C sockets layer): you pass the integer fd returned by `socket()` /
10 * `tcp_listen()` / `accept()` to the other calls. IPv4 + TCP only; host names are
11 * resolved with `getaddrinfo` (so `"localhost"`, `"127.0.0.1"`, and DNS names all
12 * work). Errors are reported as a negative return (or empty string for `recv`);
13 * `last_error()` gives the matching `errno` text.
14 *
15 * `import socket` includes this header AND links `libcheatah_socket`. Unit tests:
16 * `stdlib/tests/socket_test.cpp`; the suite runs under AddressSanitizer (the
17 * `asan` preset) and Valgrind (`security/run-valgrind.sh`) on every QA-gate run.
18 *
19 * @note Every call is a thin wrapper over one or two syscalls. Only `recv` and
20 * `last_error` allocate (their returned `std::string`); the fd/status calls
21 * return a `long long` and do not allocate.
22 */
