Class

ndarray::NDArray

An N-dimensional array of doubles: a view ({shape, strides, offset}) over a shared element buffer.

Copies are cheap and share the buffer; reshape/broadcast produce new views without copying elements. Index math goes through at, which bounds-checks.

Construct a contiguous array of shape filled with fill.

Allocates a fresh buffer of product(shape) doubles all set to fill and computes C-order (row-major) strides; the dimension product is overflow-checked.

Parameters
shape

the dimensions.

fill

value for every element.

Complexity

O(size).

Allocation

allocates a new NDArray buffer (shared_ptr<vector<double>>) of product(shape) elements; throws if the shape overflows size_t.

Construct a view from explicit buffer/shape/strides/offset (used by views).

Stores the supplied members verbatim with no validation or copy, so the new array shares ownership of data; callers (e.g. broadcast_to) are responsible for passing strides/offset that stay within the buffer.

fn double at(const std::vector< std::size_t > &index) const source#

Read one element by multi-index (via strides).

Computes the flat buffer position as offset + sum(index[i] * strides[i]), so it correctly resolves views (including broadcast dims with stride 0); throws if index has the wrong rank or any coordinate is out of range for its dimension.

Parameters
index

one coordinate per dimension.

Returns

the element value.

Complexity

O(ndim).

Allocation

none; bounds-checks rank and range, throwing on a bad index.
