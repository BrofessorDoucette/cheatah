# Read the docs

Full language documentation lives in the cheatah repository:

- **Language overview & getting started** — the repo's top-level `README.md`.
- **API reference** — the generated docs site under `docs/` (built from the
  source via `docs/build-docs.sh`).
- **Standard library** — browse `stdlib/` for the modules you can `import`
  (e.g. `io`).

This extension covers editor support only (highlighting, icons, language
configuration, and IntelliSense). The compiler (`purrc`) and runtime (`cheatah`)
live in the same repository.
