# cheatah 🐆

You've installed editor support for the **cheatah** language (`.purr`). This
extension gives you:

- **Syntax highlighting** — keywords (`let`, `fn`, `struct`, `if`/`else`,
  `while`, `for`/`in`, `try`/`except`/`raise`, `import`/`as`, `and`/`or`/`not`),
  strings, numbers, both comment styles (`#` and `//`), operators, types, and
  built-ins.
- **Real C++ inside `cpp { … }`** — the escape-hatch block body is highlighted
  with VS Code's built-in C/C++ grammar, with balanced-brace tracking.
- **Editor config** — bracket matching, auto-closing pairs, and comment
  toggling for `.purr`.
- **A cheetah file icon** for `.purr` (see the next step to turn it on).
