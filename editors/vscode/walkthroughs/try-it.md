# Open a `.purr` file

Open any `.purr` file to see highlighting in action. A good starting point is
the language tour at `stdlib/scripts/tour.purr`, which walks through structs,
functions, recursion, loops, and the `cpp { … }` escape hatch.

Compile and run it with:

```bash
purrc tour.purr -o tour.so && cheatah tour.so
```

Or paste a snippet into a new file saved with the `.purr` extension and watch
the highlighter and bracket matching kick in.
