# Turn on the cheetah file icon

The extension bundles a **cheetah 🐆 icon** for `.purr` files, shipped as the
**"cheatah (Seti + cheetah)"** file icon theme.

VS Code's default *Seti* theme overrides per-language icons, so the cheetah only
appears once you select the bundled theme explicitly:

**`Preferences: File Icon Theme` → "cheatah (Seti + cheetah)"**

It's the full Seti icon set (vendored from microsoft/vscode, MIT) with `.purr`
mapped to the cheetah — every other file keeps its familiar Seti icon.
